AOZORA. ESTIMATE NAVI PRO v15.0

重点課題：同一事故の複数損傷部位の工程重複精査

[導入]
index.html をブラウザで開くか、同封ファイルを同じフォルダにして GitHub Pages 等で公開してください。
利用に外部APIは不要です。旧版のローカル保存領域を消去しません。

[新機能]
- 「事故横断・重複精査 v15」画面
- v12工程台帳の実施登録から事故単位の重複候補を検出
- 調色、診断、車体計測、修正機セット、塗装材料、回送、ぼかし、脱着、防錆、ADAS、アライメントの確認
- 候補ごとの判定状態と根拠保存（AOZORA_OVERLAP_V15）
- CSV書き出し、判定データのJSON書き出し・復元
- 異なる損傷箇所の作業が必ず重複とは限らないため、判定は人間が実施
- 元の工程・見積の修正や削除は自動実行しません

[注意]
指数、保険会社の許容上限や認定金額の自動判定は行いません。
車種別公式指数・メーカー修理書の作業範囲・事故との因果関係・実施記録を確認してください。
現在の監査対象はv12工程台帳の実施登録のみです。全ての見積明細を漏れなく横断監査する機能ではありません。
JSONに写真画像本体は含まれません。
旧版から更新する前に各機能でJSONバックアップを取得してください。
