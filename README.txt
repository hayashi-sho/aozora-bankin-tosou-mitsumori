AOZORA. ESTIMATE NAVI PRO v10.0

1. index.html を Chrome/Safari などのブラウザで開きます。GitHub Pages に公開すると iPhone でも利用できます。
2. 「写真損傷解析 NEW」から車両写真を取り込みます。
3. 写真上で損傷位置をタップし、部位・損傷状態・修理方法を指定します。
4. 203の保険見積用確認候補から、関連する細目を検索します。候補は確認のための情報であり、請求対象の自動確定ではありません。
5. 指数・作業時間・費用・証拠を確認し、A4レポート/CSVに出力できます。

重要:
- AIの画像認識・自動損傷判定は搭載していません。写真の「送信」ではなく端末内で画像を取り込んでタップして登録する方式です。
- 写真の元データは端末内IndexedDBに保存。画像容量/プライベートモード/端末変更/サイトデータ削除で失われる場合があります。
- JSONバックアップは写真本体を含みません。元写真を別途バックアップしてください。
- 写真は最大30枚/案件、1枚18MB以下。写真データはWebブラウザの端末ストレージに依存します。
- 指数・適正金額・保険許容上限は自動生成しません。メーカー修理書、指数テーブル、事故との因果関係、協定結果を別途確認してください。
- v9の既存ファイル/保存形式を維持し、写真診断用の独立保存領域を追加しています。更新前に既存アプリからJSONバックアップしてください。
- iPhone実機やGitHub Pages上での動作検証は未実施です。
